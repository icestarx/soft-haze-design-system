# 网页视觉规范

当前交付包含可交互网页预览、[视觉规范](./visual-spec.md)和机器可读的设计令牌。本设计系统以代码、文档和网页预览作为可复用交付物。

页面设计从已有模式出发，再按业务内容组合与调整。建立新的页面视觉时，建议按以下顺序：

1. 选择页面模式：品牌首页、工作台或创作编辑器。
2. 先定义内容层级和主操作，再安排导航、侧栏、筛选与内容卡片。
3. 通过语义令牌控制色彩、边界、圆角、字体与阴影。
4. 为加载、错误、成功、空内容和窄屏布局补充状态。
5. 在预览站点中切换主题，检查视觉对比和布局稳定性。

令牌说明见 [`../docs/theming.md`](../docs/theming.md)，布局模式见 [`../docs/page-patterns.md`](../docs/page-patterns.md)。
