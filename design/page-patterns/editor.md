# 编辑器与创作流程模板

## 适用场景

分步创作、时间线编辑、图像或视频生成、复杂配置工具。

## 页面节奏

1. 轻量顶部栏：当前作品路径、保存状态和预览入口。
2. 步骤导航：让用户知道当前所处阶段，以及已经完成的步骤。
3. 页面标题与主操作：说明当前任务，提供最重要的新增或生成操作。
4. 主工作区：承载时间线、脚本或画布，获得页面最大面积。
5. 属性面板：展示随选择项变化的配置和说明。

## 视觉规则

- 当前步骤用品牌色标记，已完成步骤用成功色，未完成步骤保持中性。
- 工作区边界清晰但轻量；属性面板使用独立表面，减少视觉噪声。
- 将生成、保存、失败等反馈放在对应对象附近。
- 小屏幕下允许属性面板折叠到工作区下方，不让画布被挤到不可用。

## 实现入口

使用 `EditorTemplate`。通过 `title`、`steps`、`activeStep`、`children` 和 `inspector` 替换流程名称、工作内容和属性面板。
