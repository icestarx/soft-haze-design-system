# 工作台与功能列表模板

## 适用场景

工作台、项目列表、素材库、管理页和筛选结果页。

## 页面节奏

1. 固定侧栏：品牌、一级导航、账户信息。
2. 顶部状态栏：当前区域、保存或连接状态、账户入口。
3. 页面标题：标题与简短说明靠左，主要操作靠右。
4. 工具栏：搜索和筛选放在内容之前，保持一行内可扫读。
5. 内容区：项目卡片或表格按统一网格排列；空态和加载态占用同一内容区域。

## 视觉规则

- 侧栏保持比主内容更安静的底色，当前项使用品牌浅色底和明确文字色。
- 页面标题到筛选栏、筛选栏到内容之间使用稳定间距。
- 卡片视觉优先展示内容封面，再显示标题和次要状态。
- 窄屏时缩减侧栏宽度，保留导航文字可辨识和主内容最小宽度。

## 实现入口

使用 `WorkspaceTemplate`。通过 `title`、`description`、`activeItem`、`navItems` 和 `children` 传入页面内容。
