# 页面模板与页面模式

基础组件解决“一个按钮或卡片如何呈现”；页面模式解决“导航、标题、筛选、内容区和行动如何组合”。这套系统把二者分层维护：

```text
tokens → components → patterns → templates → product pages
```

## 当前模板

| 模板 | 适用页面 | React 入口 | 可替换内容 |
| --- | --- | --- | --- |
| 首页 | 公开入口、品牌介绍 | `HomeTemplate` | 导航、标题、说明、下方内容 |
| 工作台 | 项目列表、素材管理 | `WorkspaceTemplate` | 标题、描述、导航、页面内容 |
| 编辑器 | 分步流程、创作工具 | `EditorTemplate` | 步骤、当前步骤、主工作区、属性面板 |

完整规则在 `design/page-patterns/`。在线下本地预览站点中打开「页面模板」，可切换查看三种布局；切换主题会同时改变页面级布局中的语义颜色。

## 使用原则

- 先选页面模板，再按业务替换内容和区域；不要从空白页重新拼全部结构。
- 模板只负责布局与风格，不承载项目数据、路由或业务状态。
- 页面专属的复杂区域放入模板插槽，不要把业务逻辑塞进设计系统。
- 新页面如果经常重复出现，再提炼成新的页面模式；一次性页面直接组合现有模式即可。
