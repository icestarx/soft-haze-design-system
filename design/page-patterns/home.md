# 首页模板

## 适用场景

产品公开首页、活动入口、创作工具介绍页。

## 页面节奏

1. 顶部导航：品牌标识靠左，少量导航靠右，主行动放在最右侧。
2. 主视觉：一句短标题、一段说明、一个主行动和一个次行动；另一侧使用有品牌氛围的封面视觉。
3. 流程摘要：用 3–4 个步骤解释产品如何工作。
4. 作品展示：以横向卡片呈现真实或明确标注的示例。
5. 结束行动：重复一个清楚的下一步入口。

## 视觉规则

- 主标题是首屏最强层级，避免同时堆叠多个大标题和徽标。
- 主视觉与文字保持接近均衡的宽度；小屏幕改为文字在上、视觉在下。
- 使用雾面渐变和柔和色块承载装饰，不让装饰抢过产品内容。
- 内容区通过背景微差和留白分组，不依赖厚重边框。

## 实现入口

使用 `HomeTemplate`，透过 `links`、`title`、`description` 和 `children` 替换品牌导航、文案和下方内容区。
